nmc ​

국립중앙의료원(NMC) 병원 정보 API입니다. 병원 목록 조회와 기관 ID(hpid) 기반 상세 조회를 제공합니다.

접근 권한 안내

이 데이터는 정부데이터 원본(공공데이터포털)을 캐싱한 자료입니다. 현재는 공개되어 있으나, 추후 허가받은 사용자만 접근할 수 있도록 제한될 예정입니다.

특징 ​

  • 공공데이터포털의 데이터를 빠르게 접근할 수 있습니다.
  • 필터 조건을 세분화하고 검색 성능을 개선했습니다.

데이터 출처 ​

  • 국립중앙의료원(NMC)에 등록된 정보입니다. — https://www.nmc.or.kr
  • 대한민국 공공데이터포털에서 제공한 원본 데이터를 캐싱하여 제공합니다.
  • 원본 데이터포털과 하루 한 번 재동기화됩니다.

데이터 정확성

데이터가 잘못된 경우, 원본 제공처(국립중앙의료원 또는 공공데이터포털)의 원본 데이터 오류일 수 있습니다.

TIP

  • 값이 없는(null) 필드는 응답에서 생략됩니다.
