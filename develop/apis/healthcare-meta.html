진료과목 코드​

GET
/healthcare/meta/subjects

병원 검색의 subject 파라미터에 쓴다. 각 과목에 계열(field: 의/치/한)과 전문과목 여부(specialist)가 붙는다 — 화면이 계열로 그룹핑하고, 전문의 필터는 specialist=true 만 쓴다.

Response

200

ListResponse

FieldType항상 포함Description
itemsMetaSubject[]항상

MetaSubject

FieldType항상 포함Description
codestring항상
namestring항상
descriptionstring없을 수 있음설명
fieldstring항상면허 계열. med(의과) · dent(치과) · km(한방). 화면이 이걸로 그룹핑한다.
specialistboolean항상전문의 보드가 있는 과목인가. 치과(일반)·한방응급만 false. 전문의 필터는 true 인 것만 옵션으로 쓴다.
{
  "items": [
    {
      "code": "IM",
      "name": "내과",
      "description": "string",
      "field": "string",
      "specialist": true
    }
  ]
}

진료 분야 그룹​

GET
/healthcare/meta/subject-groups

기본 검색의 칩. 47개 진료과목을 환자가 아는 이름으로 묶은 우리 분류다.

그룹을 고르면 subjects 의 code 들을 펼쳐서 /healthcare/hospitals?subject=A,B,C 로 검색한다.
환자가 직접 가지 않는 과(영상의학·병리·진단검사 등)는 어느 그룹에도 없다.

병원 등급​

GET
/healthcare/meta/tiers

종별을 등급으로 묶은 것. 의원급(TIER1) · 병원급(TIER2) · 상급종합(TIER3).

상급종합은 진료의뢰서가 없으면 진료비 전액 본인 부담이다.
요양병원·정신병원은 이 체계 밖이라 어느 등급에도 없다(NURSING·MENTAL).

Response

200

ListResponse

FieldType항상 포함Description
itemsMetaHospitalTier[]항상

MetaHospitalTier

FieldType항상 포함Description
codestring항상TIER1 | TIER2 | TIER3
namestring항상
descriptionstring항상
classesMetaCode[]항상
└─codestring항상
└─namestring항상
└─descriptionstring없을 수 있음설명
{
  "items": [
    {
      "code": "TIER1",
      "name": "의원급",
      "description": "외래 중심. 병상 30개 미만",
      "classes": [
        {
          "code": "IM",
          "name": "내과",
          "description": "string"
        }
      ]
    }
  ]
}

건강보험심사평가원 적정성평가 분야·항목​

GET
/healthcare/meta/assessments

분야(급성질환·암질환 …) 밑에 평가항목(대장암·급성기뇌졸중 …)이 달린다. 상세 검색의 assessment 필터에 쓴다 — items 의 code 를 ?assessment=12,20 처럼 넘기면 그 항목에서 1등급(우수)을 받은 병원을 찾는다.

Response

200

ListResponse

FieldType항상 포함Description
itemsMetaAssessmentGroup[]항상

MetaAssessmentGroup

FieldType항상 포함Description
codestring항상
namestring항상
itemsMetaAssessmentItem[]항상
└─codestring항상
└─namestring항상
└─descriptionstring없을 수 있음설명
└─scopesstring[]항상이 항목이 뜨는 검색 맥락. general(일반·응급·달빛·정신) | nursing(요양). 탭에 맞는 항목만 보이게 클라이언트가 이걸로 거른다.
{
  "items": [
    {
      "code": "asm03",
      "name": "암질환",
      "items": [
        {
          "code": "IM",
          "name": "내과",
          "description": "string",
          "scopes": [
            "general"
          ]
        }
      ]
    }
  ]
}
GET
/healthcare/meta/assessments
